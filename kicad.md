# KiCad Python Automation Reliability

Use these rules when automating KiCad boards with `pcbnew`:

1. In KiCad 10, call `PCB_VIA.GetFrontWidth()` when recording an ordinary through-via diameter. Although the generated Python help advertises `GetWidth()` overloads, both the zero-argument call and a Python integer from `via.TopLayer()` can dispatch to an asserting native path and open a hidden modal warning under a headless worker. Verify a different accessor explicitly before using it for blind, buried, or layer-dependent vias.
2. Run mutation and diagnostic workers with an exact process-tree deadline and captured stdout/stderr. A native KiCad assertion can leave Python responsive but blocked on an invisible dialog, so low CPU or `Responding=True` is not completion evidence.
3. Distinguish vias from ordinary tracks before using shared `PCB_TRACK` accessors because `PCB_VIA` inherits from `PCB_TRACK` in the bindings. Prefer exact-type checks for segments and the via-specific API for vias.
4. Before launching a headless Specctra autorouter, create and resolve the parent directory of every requested DSN/SES/log output. Freerouting does not create missing output directories; it may finish a long route successfully and then discard the result when the final SES path has no parent directory.
5. For metadata-only changes to existing native boards or projects, record the original SHA-256 and line-ending convention before editing. A patch can leave an otherwise CRLF file with LF on changed lines; restore only the verified original convention with a mechanical formatting pass. Require that reversing the intended metadata changes reproduces the original byte hash, and independently compare pads, tracks, vias, fills and nets. Coordinate snapshots before edits: a worker's baseline captured after an edit is not pre-edit evidence. Refresh source-bound native reports and fabrication manifests after any authorized source-hash change, even when the geometry is unchanged.
6. Title-block and project-variable copper declarations do not set fabrication construction. Missing native `setup.stackup` can make GerberJob exports use default 0.035 mm copper and an unspecified finish even when prose requires 2 oz and ENIG. Set the explicit native construction from the controlling specification and verify emitted GerberJob copper-layer count/thickness, finish, mask/legend colours and nominal total thickness. Treat calculated dielectric remainders as nominal RFQ bookkeeping, not supplier-approved construction or impedance qualification. Never repair a mismatch by silently editing only the CAM output.
7. Inspect the actual native JSON report schema before interpreting validation counts. KiCad ERC v1 places violations inside each `sheets` entry; DRC v1 has top-level `violations`, `unconnected_items` and `schematic_parity`. Require those fields, known schemas and the requested severity coverage. A missing or unsupported result field means incomplete evidence, not zero violations; preserve and disclose configured ignored checks.
8. Native schematic PDF export can succeed while circuit symbols extend beyond the declared paper. Measure source content and oriented page extents rather than guessing a larger landscape size, then check rendered pages and PDF plot bounds for clipping. For review-only paper/title-note corrections, preserve native sources and fabrication bindings, prove all non-presentation bytes unchanged in temporary copies, and retain every original note in a readable appendix. Combined native PDFs can inherit child bookmark lists; verify the intended root titles instead of treating the outer list length as a bookmark count.
9. Do not treat PCB-file XY coordinates as an already right-handed Cartesian 3D frame. KiCad 10 STEP export negates file Y; verify the installed exporter with an origin-bound board-and-pad fixture before deriving an assembly rotation. Check F.Cu/B.Cu normals, all contact net/centre positions and rear solder-pad locations against the actual exported solids. Compute handedness in the exported Cartesian frame, not an invented file-XY/Z frame; a numeric determinant of +1 in the wrong frame can still imply a physical reflection. Keep nominal substrate, exported copper/mask bounds, extra-pad-thickness settings and unqualified solder/wire envelopes distinct.
10. Verify installed binding signatures and return contracts before a mutation worker. In KiCad 10, footprint descriptions use `SetLibDescription()`, `FootprintSave()` may return `None` after successfully writing, UUID text comes from `m_Uuid.AsString()` rather than a SWIG proxy's `str()`, and board zones can be inventoried with `list(board.Zones())`. Prove a saved footprint by reopening it and checking its native inventory. If a downstream adapter fails after a successful save, preserve and validate that exact artifact instead of reconstructing the candidate; neither a false-like writer return nor a proxy-text mismatch proves a failed write.
11. Prefer coordinate edits that preserve native item identities when the intended pad, track or outline inventory is unchanged. Combined removal/recreation and footprint mutation can expose unwrapped `SwigPyObject` containers in a headless KiCad worker even when isolated calls succeed. Treat a container that cannot be enumerated or inspected as an adapter failure, not an empty inventory. Preserve the failed stage, reproduce the smallest relevant operation, and verify a fresh saved-file readback, net identities and native ERC/DRC before accepting an alternative. Do not infer a particular ownership cause from the wrapper exception alone.
12. In KiCad 10, `GetNetsByName()` can expose `wxString` map keys rather than Python `str`. Do not pass those keys into string-based net filters: a skip set can silently fail to restrict routing. Build a dictionary from verified `pad.GetNetname()` strings and `pad.GetNet()` objects when the task concerns pad-bearing nets, or validate another accessor for the required net inventory. Before mutation, assert that the effective routing target set is exactly the reviewed allowlist. Test key types and included/excluded nets against the installed bindings; preserve and inspect any saved candidate after a filtering mistake instead of rerunning it blindly.
13. Check coordinate-unit conversions before exact native endpoint assertions. KiCad 10 `FromMM()` can truncate a binary floating-point value one nanometre below the intended decimal coordinate (for example, 67.0889 mm). For an exact nominal decimal, form and verify the intended integer nanometres explicitly, such as `round(value * 1_000_000)`, and retain native integer coordinates for identity comparisons. Do not relax a geometric clearance gate to mask a conversion mismatch. If a completed placement or save precedes the failed assertion, resume from that hash-bound artifact after correcting the adapter instead of repeating the geometry edits.
14. Inventory physical pads by their unique native UUIDs, not only by `(reference, pad number)`. Multiple pads can share a number, and mechanical pads can have blank numbers; a dictionary keyed by the electrical label silently drops physical geometry. Report physical pad count, unique UUID count and distinct electrical-label count separately. Compare every pad's full geometry, layers and net identity, including duplicate-number and non-electrical pads, and include a duplicate-number fixture before claiming a complete inventory audit. Retain an electrical lookup only for its declared routing purpose; do not present its key count as the physical pad count.
15. For identity-preserving library-footprint edits, verify whether the loader regenerates UUIDs. KiCad 10's default `pcbnew.FootprintLoad()` can assign new identities to every pad and property before any intended edit. Where the installed plugin supports it, `pcbnew.PCB_IO_KICAD_SEXPR().FootprintLoad(path, name, True)` requests pad UUID preservation; KiCad 10.0.5 can still regenerate property-field UUIDs with that option. Independently compare the complete saved library tree with its original, allowing only explicitly intended fields. For a bounded source-layer edit that needs every identity retained, a mechanical native-source transformation followed by full expected-tree comparison can avoid loader churn; never substitute manual CAM edits. Preserve failed stages for diagnosis and resume from the unchanged original rather than accepting unrelated identity changes.
16. A standalone schematic's embedded symbols do not register its project-local library for CLI ERC. Supply the exact matching library, `sym-lib-table`, and a matching `.kicad_pro` beside the schematic before relying on `${KIPRJMOD}` library resolution. Verify that library-configuration warnings disappear through a fresh native check, without changing schematic connectivity or ignored-check policy. Netlist export may also return zero while reporting annotation errors; inspect the diagnostics and compare the full exported reference/pin/net/type inventory. Preserve earlier reports, and do not classify unresolved external power or control ports as a clean ERC result.
